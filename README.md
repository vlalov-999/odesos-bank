# Одесос Банк - кредитен калкулатор (версия 2)

Демонстрационен фронтенд проект на HTML5, CSS3 и чист JavaScript. Без външни фреймуърци (без jQuery, React и др.).

## Какво е променено спрямо версия 1
- Използват се само стандартни тирета (дефис "-"), без "en dash" и "em dash".
- Опростен CSS, по-близък до студентско ниво, но със същата тема и функции.
- Повече коментари в HTML, CSS и JavaScript.
- Стандартен CSS без браузър-специфичен код (без -webkit- и -moz-); плъзгачите и радио бутоните се оцветяват със стандартния accent-color, който работи еднакво в Chrome, Firefox, Edge и Safari.

## Стартиране
Отворете index.html в браузър. Калкулаторът и запазването на сценарии работят и при директно отваряне.

За по-надеждно тестване пуснете локален сървър от папката на проекта:

    python3 -m http.server 8000

После отворете http://localhost:8000

## Тестване на телефон / таблет
1. Пуснете локален сървър на компютъра.
2. Свържете телефона/таблета в същата WiFi мрежа.
3. Намерете локалния IP на компютъра (например 192.168.0.10).
4. На устройството отворете http://192.168.0.10:8000

Или качете папката на безплатен хостинг (GitHub Pages, Netlify) за достъп от всяко устройство.
